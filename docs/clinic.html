Instagram の連携のお願い（約5分）

毎日の投稿を自動で行うために、3つだけお願いします。パスワードを教えていただく必要はありません。

1
Instagram を「プロアカウント」にする

Instagram アプリ → プロフィール右上の ≡ → 設定とプライバシー → アカウントの種類とツール → プロアカウントに切り替える → カテゴリを選び「ビジネス」を選択。Facebook との連携は「今はしない」で大丈夫です。すでにプロアカウントなら、そのままで結構です。

2
「テスター招待」を承認する

担当者から招待をお送りします。Instagram アプリ → ≡ → 設定とプライバシー → ウェブサイトのアクセス許可 → アプリとウェブサイト → テスター招待 に表示される招待を承認してください。

3
送られたリンクを開いて「許可」を押す

担当者から届く「許可リンク」を、Instagram にログインしているスマホで開き、許可を押してください。表示されたコードをコピーして、担当者に送り返していただければ完了です。

投稿の内容・頻度・デザインは担当者が設定します。投稿を止めたいとき、内容を変えたいときは、担当者にご連絡ください。
