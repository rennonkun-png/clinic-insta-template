Instagram 自動投稿セットアップ画面
    0 / 6 完了

    1時間で、毎日の投稿が自動になります

    歯科・医科クリニック向けの Instagram 毎日自動投稿システムです。費用は0円。進め方は2通りあります。

    どちらで進めますか？

    医院が自分で設定するこの画面の Step 1〜5 を上から順に（約1時間）。GitHub と Meta の登録を医院側で行います。チェックは自動で保存されます。
    運用会社がまとめて設定する医院は「プロアカウント化」と「許可リンクをタップ」だけ（約5分）。残りは運用会社がコマンド1本で行います。→ 運用者ガイド ／ 医院に送るページ → 医院向けのお願い

    できること

    毎日自動投稿診療科に合った健康コラムを、指定した曜日・時間に投稿。デザインは伸びている投稿の分析に基づく型（表紙は 1 メッセージ・大きな文字、2 枚目に目次、1 枚 1 ポイント、まとめ、CTA は 1 つ）。背景写真は投稿内容に合わせて AI が毎回生成します
    目的に合わせて最適化「伸びる投稿」「リール」「フォロワー増」「集患」を選ぶと、形式や文末の呼びかけが自動で変わります
    サービス紹介ホワイトニング・矯正・美容点滴など提供中のサービスに関する投稿の最後に、ご案内を自動で添えます
    毎週、分析して賢くなる反応の良いテーマ・形式・切り口を学習し、次の投稿に反映します
    AIでネタ生成（任意）医院のHPや資料を読み込んで投稿ネタを作成。好調な傾向から新ネタも自動追加

    用意するもの

    複数の医院で使う場合は、医院ごとにこの手順を繰り返します（Step 3 の GitHub リポジトリを医院ごとに作成）。自社のWEB情報発信アカウントも同じ手順で、診療科に「クリニックWEB集患コラム」を選ぶだけです。

    Instagram をプロアカウントにする

    自動投稿には「ビジネス」または「クリエイター」アカウントが必要です。すでにプロアカウントなら、下のチェックを付けて次へ進んでください。Facebookページとの連携は不要です。

    Meta 開発者サイトでトークンを取得する

    いちばん手間のかかる工程です（15〜20分）。最後に Instagram ユーザーID と アクセストークン の2つを手元に控えます。

    トークンはパスワードと同じです。 メールやチャットに貼らず、Step 3 で GitHub の「Secrets」にだけ保存してください。有効期限は60日ですが、システムが毎日自動で延長します。
    権限の画面で確認すること

    instagram_business_basic、instagram_business_content_publish、instagram_business_manage_insights の3つがオンになっていればOKです。

    アプリの「公開」や審査は必要？

    不要です。自分の医院アカウントだけに投稿するなら、開発モードのままで動きます。

    GitHub にプログラムを置く

    GitHub は無料で毎日プログラムを動かしてくれる場所です。画像の公開場所も兼ねます。

    背景写真をきれいに出すために（おすすめ・無料）

    投稿の背景写真は AI が毎回生成します。キー無しでも動きますが、混雑時に失敗したり指示どおりに描かれないことがあります。Cloudflare の無料アカウントを登録すると、安定して投稿内容どおりの写真が出ます（5分・費用0円・1日あたり十分な無料枠）。

    代わりに Hugging Face の無料トークンを HF_TOKEN として登録しても動きます。医院の写真を使いたい投稿は、投稿データに image_path を指定すれば AI 生成の代わりに使われます。

    任意: AI でネタを自動生成する
    ANTHROPIC_API_KEY医院のHPからネタ生成・週次ブラッシュアップをする場合に登録（従量課金・月数百円程度）

    医院の設定を作る

    入力して「設定ファイルを作る」を押すと、貼り付け用の内容ができます。最低限は医院名・診療科・目的の3つだけでも動きます。

    詳細設定（必要なときだけ）

    投稿時刻は GitHub の .github/workflows/daily-post.yml の cron 行で変更します（初期値：日本時間 12:00）。

    よくある操作

    ネタを足す・直すcontent/ の診療科ごとのファイルを編集。医院独自のお知らせは content/custom.json に。"date": "2026-12-01" を付けるとその日に必ず投稿
    医院の写真を使う投稿に "image_path": "assets/photos/xxx.jpg" を付けると AI イラストの代わりに使われます
    ロゴを入れるassets/logo.png（背景透過）を置き、設定の logo_path に assets/logo.png
    院長・スタッフの写真を入れる伸びている投稿のほとんどに「誰が言っているか」の写真があります。背景を透過したPNG（例: assets/doctor.png）を置き、設定の person_image に指定すると、表紙とリールの右下に入ります
    サービスを増やした設定の services に追加するだけ（例：美容点滴を始めたら beauty_iv）
    休診・年末年始設定の skip_dates に日付を追加
    一時停止Actions → 「Instagram 毎日自動投稿」→ 右上「…」→ Disable workflow
    手動で投稿したい（Meta アプリの準備前など）フォルダ内の 手動投稿を作る.bat をダブルクリック（または python scripts/manual_batch.py --days 7）。7日分の画像とキャプションが output/manual/ にでき、一覧ページから保存・コピーして Instagram や Meta Business Suite の予約投稿に貼り付けます。自動投稿と同じネタ選び・デザインで、履歴も共有されます
    トークンの期限毎日自動延長。60日以上止めていた場合は Step 2 で再発行して Secrets を更新

    AIでネタを作る（任意）

    医院のHPや資料を読み込んで、投稿ネタ20件と提供サービス・ご案内文を作ります。パソコンで実行します。

    pip install -r requirements.txt
set ANTHROPIC_API_KEY=sk-ant-...
python scripts/ai_generate.py --url https://医院のHP/ --file 診療案内.pdf --notes "11月から美容点滴を開始" --count 20 --apply-services

    週次の自動ブラッシュアップ（好調な傾向から新ネタ7件・不調ネタの引退）は、ANTHROPIC_API_KEY を Secrets に入れると自動で動きます。AI生成の文章も医療広告ガイドラインを前提にしていますが、公開前に一度目を通すことをおすすめします。

    困ったとき

    Actions が赤い × で失敗する

    実行結果の「投稿を実行」のログを確認してください。よくある原因：Secrets の名前のタイプミス／トークンの期限切れ（Step 2 で再発行）／Pages 未設定（Step 3）／Workflow permissions が Read のまま（Step 3）

    「公開されませんでした」と出る

    GitHub Pages の設定（Branch: main / /docs）を確認。初回は反映に10分ほどかかることがあります。時間をおいて再実行してください。

    「アカウントが ビジネス/クリエイター ではありません」

    Step 1 でプロアカウントに切り替えてから、Step 2 の Generate token をやり直してください。

    背景写真が入らない・内容と合わない

    キー無しの無料AI（Pollinations）は混雑で失敗したり、指示と違う写真になることがあります。投稿自体は文字だけのデザインで続きます。Step 3 の「背景写真をきれいに出すために」の Cloudflare 設定（無料）をおすすめします。

    画像の文字が □ になる

    フォントのインストールに失敗した場合です。Actions を再実行してください。
