運用者ガイド：複数の医院をまとめて動かす

運用会社（旅河さん側）が GitHub と Meta アプリを1つ持ち、医院には「プロアカウント化」と「許可リンクをタップ」だけをお願いする方式です。医院ごとの追加はコマンド1本で終わります。

最初に1回だけ（約40分）

医院を1件追加する（約10分・医院の操作は5分）

セットアップが自動でやること

リポジトリテンプレートから医院用を作成（Public。トークンは Secrets なので公開されません）
SecretsIG_ACCESS_TOKEN / IG_USER_ID に加え、operator.json にある Cloudflare・Anthropic・Hugging Face のキーを配布
設定GitHub Pages（main / docs）、Actions の書き込み権限、config/clinic.json の生成とコミット
テストDRY_RUN のワークフローを起動（画像だけ作って投稿しない）

運用中によくある作業

医院の設定を変えるその医院のリポジトリで config/clinic.json を編集（GitHub 上で直接編集可）
院長の写真を入れる背景透過 PNG を assets/doctor.png に置き、person_image に指定
ネタを HP から作るpython scripts/ai_generate.py --url https://医院HP/ --count 20 --apply-services（ANTHROPIC_API_KEY が必要）
投稿を止めるActions → 「Instagram 毎日自動投稿」→ Disable workflow
トークン切れ（60日以上停止した場合）許可リンクを再送 → get_token.py --code → リポジトリの Secrets を更新
成果を見る各医院の Pages（設定画面の「運用とレポート」）。毎週月曜に自動更新
Meta アプリが「開発モード」の間は、テスターとして追加した Instagram アカウントだけが連携できます（医院数の上限は実質ありません）。将来、テスター承認の手間をなくしたい場合は Meta の「アプリレビュー」を通すと、どの医院もリンクをタップするだけで連携できます。
